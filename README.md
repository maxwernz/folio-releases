# Folio

A local-first study app for your lecture material. A Mac app.

This repository holds the builds: download the latest from [Releases](https://github.com/maxwernz/folio-releases/releases/latest). Choose the `arm64` disk image for an Apple silicon Mac, `x64` for an Intel one. Open it and drag Folio into Applications. From then on Folio offers new versions itself.

The app is not signed with an Apple developer certificate, so macOS blocks it the first time you open it. Open System Settings, go to Privacy & Security, and choose Open Anyway next to Folio.
